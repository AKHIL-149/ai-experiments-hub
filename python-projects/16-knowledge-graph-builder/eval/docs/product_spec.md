# Widget-X Sensor

The Widget-X sensor is manufactured by Beta Systems in Munich. It uses the Zeta-9 processor, which is produced by Orion Semiconductors. The Widget-X replaced the Widget-W in 2021. Beta Systems sells the Widget-X to Nordwind Robotics and to Orbis Logistics. The sensor complies with the ISO 13849 safety standard. Firmware updates for the Widget-X are published by Beta Systems every quarter.
